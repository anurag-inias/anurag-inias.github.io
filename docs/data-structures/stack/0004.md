## Solution

??? "First approach"

    Instead of simply saving the element, we save a pair `(element, new_min)`.

    ```kotlin
    class MinStack() {

      private val stack = ArrayDeque<Pair<Int, Int>>()

      fun push(x: Int) {
        if (stack.isEmpty()) {
          stack.push(x to x)
        } else {
          stack.push(x to min(x, stack.last().second))
        }
      }

      fun pop() = stack.removeLast().first

      fun top() = stack.last().first

      fun getMin() = stack.last().second

    }
    ```

??? "Second approach"

    We can save some space (still $O(n)$ though) by not saving the explicit $min$ but rather encode it in the stack itself.

    We will maintain a simply stack of `int` underneath and keep track of the current `min`. Let's say the stack at some point is:

    $$
    \begin{align}
    stack &= [\dots, M) \\
    min &= M
    \end{align}
    $$ 

    === "Pushing $x \ge M$"

        If we try to push a number $x \ge M$, we simply push it as is:

        $$
        \begin{align}
        stack &= [\dots, M, x) \\
        min &= M
        \end{align}
        $$

    === "Pushing $m < M$"

        If we try to push a number $m < M$, we actually insert $2m - min$ and update $min$.

        $$
        \begin{align}
        stack &= [\dots, M, 2m - M) \\
        min &= m
        \end{align}
        $$

        Note that:

        $$
        \begin{align}
        m &< M \\
        2m &< M+m \\
        2m-M &< m \\
        \end{align}
        $$
    
    So we can use the check $top < min$ as a tripwire to figure out if the top of the stack is the encoded or not. It can be recovered by:

    $$
    \begin{align}
    & 2 \cdot min - top \\
    \implies & 2m - (2m-M) \\
    \implies & M
    \end{align}
    $$ 

    ```kotlin
    class MinStack() {

      private var min = 0
      private val stack = ArrayDeque<Int>()

      fun push(x: Int) {
        if (stack.isEmpty()) {
          stack.add(x)
          min = x
        } else if (x < min) {
          stack.add(2 * x - min.toInt())
          min = x
        } else {
          stack.add(x)
        }
      }

      fun pop(): Int {
        val top = stack.removeLast()
        if (top < min) { // it's been converted
          return min.also {
            min = 2 * min - top
          }
        }
        return top
      }

      fun top(): Int {
        val top = stack.last()
        if (top < min) { // it's been converted
          return min
        }
        return top
      }

      fun getMin() = min

    }
    ```

    !!! tip

        We need to switch to `Long` for both `min` and `stack` types to pass the test suite.
