# [496. Next Greater Element (i)](https://leetcode.com/problems/next-greater-element-i/description/){target="_blank"}

## Description

The next greater element of some element $x$ in an array is the first greater element that is to the right of $x$ in the same array.

You are given two distinct 0-indexed integer arrays $nums_1$ and $nums_2$, where $nums_1$ is a subset of $nums_2$.

For each $0 \le i < |nums_1|$, find the index $j$ such that $nums_1[i] == nums_2[j]$ and determine the next greater element of $nums_2[j]$ in $nums_2$. If there is no next greater element, then the answer for this query is $-1$.

Return an array $ans$ of length $|nums_1|$ such that $ans[i]$ is the next greater element as described above.

## Example

> Input : nums1 = [4,1,2], nums2 = [1,3,4,2]
> 
> Output: [-1,3,-1]
>
> Explanation: The next greater element for each value of nums1 is as follows:
> 
> - 4 is underlined in nums2 = [1,3,4,2]. There is no next greater element, so the answer is -1.
> - 1 is underlined in nums2 = [1,3,4,2]. The next greater element is 3.
> - 2 is underlined in nums2 = [1,3,4,2]. There is no next greater element, so the answer is -1.

## Constraint

- All integers in $nums_1$ and $nums_2$ are unique.
- All the integers of $nums_1$ also appear in $nums_2$.

## Problem explanation

This is a pointlessly convoluted problem. For a moment forget about $nums_1$ and $nums_2$. Instead, we are actually asked to complete this method:

```kotlin
fun helper(index: Int, nums2: IntArray): Int {
  // Fill here
}
```

That is, given an array of integers $nums$, we are asked to look to the right of the specified $index$ and find the first element $e > nums_{index}$.

Now the actual problem calls this `helper` repeatedly with a bunch of indices.

## Solution

??? "Expand"

    We just iterate from right-to-left, populating a stack with the values we have encountered.

    At each iteration, at index $i$ and value $v$:

    - we keep popping the stack until the stack elements $e \le v$.
    - if the stack ends up empty, that means there is no element greater than $v$ to its right.
    - otherwise, the remaining element on the stack is its NGE.

    ```kotlin
    fun nextGreaterElement(queries: IntArray, nums: IntArray): IntArray {
      val nge = IntArray(nums.size)
      val stack = ArrayDeque<Int>()
      for ((i, v) in nums.withIndex().reversed()) {
        while (stack.isNotEmpty() && stack.last() <= v) {
          stack.removeLast()
        }
        nge[i] = if (stack.isEmpty()) -1 else stack.last()
        stack.addLast(v)
      }

      for ((i, q) in queries.withIndex()) {
        queries[i] = nge[nums.indexOf(q)]
      }
      return queries
    }
    ```
