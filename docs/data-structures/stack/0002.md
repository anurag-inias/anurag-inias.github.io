## Solution

??? "First approach"

    $O(n)$ push and $O(1)$ pop.

    Maintain two internal stacks, where `(`/`)` represent the top of the stack:
  
    ```
    Beginning | aux = [)        stack = (1, 2, 3]

    push(4)   | aux = [1, 2, 3) stack = (]
              | aux = [1, 2, 3) stack = (4]
              | aux = [)        stack = (1, 2, 3, 4]

    pop()     | aux = [)        stack = (2, 3, 4]
    ```

    ```kotlin
    class MyQueue() {
      private val stack = ArrayDeque<Int>()
      private val aux = ArrayDeque<Int>()

      fun push(x: Int) {
        unload(stack, aux)
        stack.add(x)
        unload(aux, stack)
      }

      fun pop(): Int = stack.removeLast()

      fun peek(): Int = stack.last()

      fun empty(): Boolean = stack.isEmpty()

      private fun unload(from: ArrayDeque<Int>, to: ArrayDeque<Int>) {
        while(from.isNotEmpty()) {
          to.addLast(from.removeLast())
        }
      }
    }
    ```

    $O(1)$ push and $O(1)$ pop (amortized).

    The "move-to-aux" is not wasteful, but the "move-back-from-aux". We can simply check if `aux` is empty or not to figure out our current state, and only move back element if a `pop` is called.

    ```kotlin
    class MyQueue() {

      private val stack = ArrayDeque<Int>()
      private val aux = ArrayDeque<Int>()

      fun push(x: Int) {
        stack.addLast(x)
      }

      fun pop(): Int {
        if (aux.isEmpty()) {
          unload(stack, aux)
        }
        return aux.removeLast()
      }

      fun peek(): Int {
        if (aux.isEmpty()) {
          unload(stack, aux)
        }
        return aux.last()
      }

      fun empty(): Boolean = stack.isEmpty() && aux.isEmpty()

      private fun unload(from: ArrayDeque<Int>, to: ArrayDeque<Int>) {
        while(from.isNotEmpty()) {
          to.addLast(from.removeLast())
        }
      }
    }
    ```

    So for example

    | Step | Result | `aux` | `stack | Explanation |
    |------|-------|-------|--------|-------------|
    |      | | `[)`  | `(]`   |             |
    | `push(1)` | | `[)`  | `(1]`   | Always `push` to `stack` |
    | `push(2)` | | `[)`  | `(2, 1]`   | Always `push` to `stack` |
    | `push(3)` | | `[)`  | `(3, 2, 1]`  | Always `push` to `stack` |
    | `pop()` | 1 | `[3, 2, 1)` | `(]`  | `aux` is empty so move elements `stack -> aux` |
    |         | | `[3, 2)`  | `(]`  | then pop `aux` |
    | `pop()` | 2 | `[3)`  | `(]`  | `aux` is **not** empty so simply pop `aux` |
    | `push(4)` | | `[3)`  | `(4]`  | Always `push` to `stack` |
    | `push(5)` | | `[3)`  | `(5, 4]`  | Always `push` to `stack` |
    | `pop()` | 3 | `[)`  | `(5, 4]`  | `aux` is **not** empty so simply pop `aux` |
    | `pop()` | 4 | `[5, 4)`  | `(]`  | `aux` is empty so move elements `stack -> aux` |
    |         | | `[5)`  | `(]`  | then pop `aux` |
