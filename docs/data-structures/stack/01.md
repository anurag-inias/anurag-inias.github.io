# Valid Parentheses

Given a string $s$ containing just the characters `(`, `)`, `{`, `}`, `[`, and `]`, determine if the input string is valid.

An input string is valid if:

1. Open brackets must be closed by the same type of brackets.
2. Open brackets must be closed in the correct order.
3. Every close bracket has a corresponding open bracket of the same type.

## Example

| String | Valid |
|--------|-------|
| `()`   | Yes   |
| `()[]{}` | Yes |
| `(]` | No |
| `([])` | Yes |
| `([)]` | No |

## Solution

??? "First approach"

    $O(n)$ time and $O(n)$ space.

    1. When encountering an opening bracket, push it to the stack.
    2. When encountering a closing bracket, see if a corresponding opening bracket is at the top of the stack.

      1. If not, or if the stack is empty, then it's not a valid expression.
      2. Otherwise, simply pop the corresponding opening bracket.

    3. if the stack is empty then it's a valid expression.

    ```kotlin
    fun isValid(s: String): Boolean {
      val stack = ArrayDeque<Char>()
      for (c in s) {
        when(c) {
          '(', '{', '[' -> stack.push(c)
          else -> when {
            stack.isNotEmpty() && stack.peek() == c.companion -> stack.pop()
            else -> return false
          }
        }
      }
      return stack.isEmpty()
    }

    private val Char.companion: Char
      get() = when(this) {
        ')' -> '('
        '}' -> '{'
        ']' -> '['
        else -> '\n'
      }

    // Because these just look neat.
    private fun <T> ArrayDeque<T>.push(v: T) { add(v) }
    private fun <T> ArrayDeque<T>.pop() = removeLastOrNull()
    private fun <T> ArrayDeque<T>.peek() = lastOrNull()
    ```

??? "Second approach"

    $O(n)$ time and $O(1)$ space.

    Only possible if the input itself is mutable.

    ```cpp
    bool isValid(std::string s) {
      int top = 0;

      for (int i = 0; i < s.length(); i++) {
        if (s[i] == '(' || s[i] == '{' || s[i] == '[') {
          s[top++] = s[i];
          continue;
        }

        if (s[i] == ')') {
          if (top == 0 || s[top - 1] != '(') return false;
          top--;
        } else if (s[i] == '}') {
          if (top == 0 || s[top - 1] != '{') return false;
          top--;
        } else {
          if (top == 0 || s[top - 1] != '[') return false;
          top--;
        }
      }
      return top == 0;
    }
    ```
